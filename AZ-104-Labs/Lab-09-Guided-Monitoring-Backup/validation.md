## Exam-Readiness Validation

The lab is complete when these can be explained without notes:

- Metrics are numeric time-series data.
- Logs are detailed records/events.
- Diagnostic settings send logs/metrics to destinations.
- Log Analytics stores and queries logs.
- KQL is the log query language.
- Metric alerts are for numeric thresholds.
- Log search alerts are based on KQL.
- Activity log alerts are for management-plane events.
- Action groups define notifications/actions.
- Alert processing rules suppress or modify alert notifications.
- VM insights provides VM performance/dependency monitoring.
- Connection Monitor tracks connectivity over time.
- Recovery Services vault commonly supports Azure VM backup and ASR scenarios.
- Backup vault supports newer backup workloads where applicable.
- Backup policy defines schedule and retention.
- Azure Backup restores data/VM state.
- Azure Site Recovery provides DR/failover.
- Test failover validates DR without impacting production.
